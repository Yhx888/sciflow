使用方式

三种方式，任你选择

桌面应用、Web界面、命令行，同一套核心引擎，适配不同场景。

🖥️
桌面应用

原生 App 体验

基于 WebView2 的原生桌面窗口，类似 Notion / Obsidian 的使用体验。

$ sciflow-app
🌐
Web 界面

精致 Web UI

ChatGPT 级交互设计，流式对话响应，深浅主题自动切换。

$ sciflow demo
⌨️
命令行

CLI 全流程

一条命令完成从主题到论文的完整流程，适合开发者与自动化场景。

$ sciflow pipeline run --topic "研究主题" --mock
